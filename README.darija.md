# التحكم بالحاسوب عبر تيليجرام (بالدّارجة)

> **تحكم في حاسوبك الويندوز من تيليجرام أو المتصفح — بكل المميزات.**
> شغل التطبيقات، وصور الشاشة، وسير الملفات، وجدول التشغيل، وطفي الحاسوب ولا شعلو — كامل من تيليفونك ولا المتصفح.

## شنو فيها؟

| المجال | شنو كتربح |
|---|---|
| 🤖 **بوت تيليجرام** | قائمة بالأزرار ديال تطبيقاتك؛ زيد وبدل وحذف التطبيقات عن بعد؛ وتشغيل بضغطة وحدة |
| ⌨️ **أزرار سريعة** | لوحة دائمة: السكرين، الملفات، السجل، الإيقاف، بدء التشغيل، فتح الواجهة، اللغة |
| 📸 **السكرين شوت** | صور شاشة الحاسوب وتوصلك في تيليجرام، ولا شوفها في واجهة الويب (بلا أدوات زايدة) |
| 📁 **الملفات** | قلب في الأقراص والمجلدات، وهبط الملفات من الحاسوب للتيليفون (حتى 45MB)، وصيفط الملفات من التيليفون للحاسوب؛ والرفع والتحميل من الويب حتى هو، مع مختار مجلدات ديال ويندوز |
| ⏰ **الجدولة** | برمج أي تطبيق يخدم من بعد؛ الجدولة كتبقى محفوظة وخا يطفى السيرفر؛ ولغيها من تيليجرام ولا الويب |
| 🕘 **السجل والخدامة** | تتبع حي للعمليات مع أزرار إيقاف لكل تطبيق، وحالة تطبيقات الإقلاع، وسجل آخر التشغيلات |
| 🔥 **بدء التشغيل** | تشغيل تلقائي لكل تطبيق مع إقلاع ويندوز + زر بدء السيرفر مع ويندوز |
| ⚡ **إجراءات سريعة** | قفل الحاسوب، تفريغ سلة المحذوفات، تصغير كل النوافذ، حل مدير المهام |
| 🌐 **واجهة الويب** | لوحة داكنة بالعربية والإنجليزية: سير التطبيقات، التشغيل والإيقاف، الجدولة، الملفات، السكرين، الإعدادات، النسخ الاحتياطي، وصيفط الرسائل والملفات لتيليجرام |
| 💾 **النسخ الاحتياطي** | صدر الإعدادات كاملة ورجعها بصيغة JSON من واجهة الويب |
| 🛡️ **الأمان** | الإطفاء والتشغيل كيطلبو تأكيد؛ والبوت خدام غير مع الـ Chat ID ديالك؛ وحماية من الضغط المكرر |
| 🌍 **جوج لغات** | العربية الكاملة (RTL) والإنجليزية في البوت والواجهة والتوثيق |
| 🎭 **ثيم شيطاني / ملائكي** | جناحين ديال الخفاش + جمر طالع (شيطاني) مقابل جناحين ديال الريش + هالة + أنوار نازلة (ملائكي)؛ زر واحد للتبديل، والاختيار كيتحفظ |
| 🐚 **الأصداف** | `cmd` وباورشل وGit Bash؛ وكل تطبيق يقدر يجمع عدة أوامر |

## الثيمات

واجهة الويب فيها جوج ثيمات متحركين كتبدل بينهم بزر 😇/😈 (الاختيار كيتحفظ):
**شيطاني** — جناحين ديال الخفاش مع جمر طالع وعلامة "H3LL G4T3"؛ **ملائكي** —
جناحين ديال الريش وهالة كتشعل وأنوار نازلة مع علامة "ANGEL GATE".

## شنو خاصك؟

- ويندوز 10/11
- Node.js 18+ (تحقق بـ `node --version`)
- توكن بوت من [@BotFather](https://t.me/BotFather) + الـ Chat ID من [@userinfobot](https://t.me/userinfobot)

## التثبيت

```bash
git clone https://github.com/xbitoi/terminal-telegram-control.git
cd terminal-telegram-control
npm install
node server.js
```

حل **http://localhost:3770** في المتصفح. أو نقر مزدوج على `run.bat`.
التثبيت الجديد كيبدا بستة تطبيقات ويندوز واجدة (التشغيل، الإطفاء، القفل، المفكرة، الحاسبة، مدير المهام) — وزيد دياولك من تيليجرام `/add` ولا من الواجهة.
باش يخدم مع إقلاع ويندوز، خدم `install-startup.ps1` (بلا صلاحيات مدير) ولا فعلو من الواجهة / قائمة 🔥 في تيليجرام.

## الإعداد

**من الواجهة (مستحسن):** حل الصفحة → *إعدادات تيليجرام* → لصق التوكن +
Chat ID (ومجلد التنزيل واللغة) → *حفظ*. البوت كيخدم مباشرة.

**من الملف:** نسخ القالب وعمرو:

```bash
cp config.example.json config.json
```

> `config.json` متجاهل في git. عمرك ما تنشر التوكن الحقيقي.

## الاستعمال

### تيليجرام

صيفط `/start` → قائمة بالأزرار ديال تطبيقاتك. ضغط للتشغيل (الإطفاء والتشغيل
كيطلبو تأكيد أولاً)، ولا سيرها بأزرار ➕ زيادة / ✏️ تعديل / 🗑 حذف / ⏹️ إيقاف.

| الأمر | شنو كيدير |
|---|---|
| `/start` و`/menu` | القائمة الرئيسية (التطبيقات) |
| `/screenshot` | تصوير شاشة الحاسوب |
| `/files` | تقليب ملفات الحاسوب |
| `/history` | التطبيقات الخدامة وتطبيقات الإقلاع وآخر التشغيلات |
| `/stop` | إيقاف تطبيق خدام |
| `/startup` | إعدادات التشغيل مع إقلاع ويندوز |
| `/schedules` | التشغيلات المبرمجة (ضغط للإلغاء) |
| `/add` و`/edit` و`/delete` | تدبير التطبيقات |
| `/lang` | تبديل اللغة (عربي/إنجليزي) |
| `/browser` | حل واجهة الويب على الحاسوب |

لوحة الأزرار السريعة (⌨️ تحت بلاصة الكتابة) كتعطيك السكرين والملفات والسجل
والإيقاف وبدء التشغيل واللغة بنقرة. وأي تصويرة ولا فيديو ولا ملف صيفطيه
للبوت كيتحفظ مباشرة في مجلد التنزيل على الحاسوب.

### واجهة الويب

حل `http://localhost:3770`: خدم التطبيقات بـ ▶ وحبسها بـ ⏹، وفعل التشغيل
التلقائي لكل تطبيق مع الإقلاع، وبرمج التشغيل، وقلب الملفات ورفعها وهبطها،
وصور الشاشة، وبدل إعدادات تيليجرام، وخدم الإجراءات السريعة، ودير نسخة
احتياطية ورجعها.

### زيادة التطبيقات

كل تطبيق عندو سمية وأمر واحد ولا أكثر. أمثلة:

| التطبيق | الأوامر |
|---|---|
| المفكرة | `notepad` |
| إعادة تشغيل الحاسوب | `shutdown /r /t 3` |
| إطفاء الحاسوب | `shutdown /s /t 0` |

زيدها من تيليجرام (`/add` كيسولك: السمية ثم الأمر) ولا من واجهة الويب.

## بنية المشروع

```
terminal-telegram-control/
├── server.js               # سيرفر HTTP + بوت تيليجرام (كامل المميزات)
├── public/index.html        # واجهة ويب داكنة باللغتين
├── config.json              # تطبيقاتك وأسرارك (git-ignored، كتصايبو انت)
├── config.example.json      # قالب البداية (التشغيل/الإطفاء/المفكرة)
├── run.bat                  # تشغيل بنقرة مزدوجة لويندوز
├── install-startup.ps1      # تسجيل بدء التشغيل مع ويندوز (بلا مدير)
├── test-per-app-startup.sh  # اختبارات ميزة التشغيل التلقائي
└── package.json
```

## الأمان

- البوت كيتجاهل الرسائل من أي Chat ID آخر من غير ديالك.
- الإطفاء والتشغيل كيطلبو تأكيد صريح دائماً.
- التوكن كيبان مقتطع في كل بلاصة؛ والقيمة الكاملة غير في `config.json` المحلي.
- حافظ على سرية توكن البوت. إلا تسرب لغيه عبر [@BotFather](https://t.me/BotFather) ← `/revoke`.
