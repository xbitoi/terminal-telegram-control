# التحكّم بالحاسوب عبر تيليجرام

> **تحكَّم في حاسوبك العامل بنظام ويندوز من تيليجرام أو المتصفّح — ثلاثة إجراءات ثابتة فقط.**
> إعادة التشغيل، وإيقاف التشغيل، وفتح المفكّرة. دون أوامر حرّة، ودون مفاجآت.

## لماذا هذا المشروع؟

معظم أدوات التحكّم عن بُعد تنفّذ أيّ أمرٍ ترسله إليها — وهذا عمليّ، لكنّ تسرّب رمز
البوت يعني تنفيذاً كاملاً للأوامر عن بُعد على حاسوبك. اتّخذ هذا المشروع المنحى
المعاكس: لا يستطيع الخادم تشغيل سوى **ثلاثة أوامر مصرّح بها**، وكلّ ما عداها
مرفوض. آمن، وسهل المراجعة.

| الإجراء | الأمر المنفَّذ | تأكيد |
|---|---|---|
| 🔄 إعادة التشغيل | `shutdown /r /t 3` | نعم — تيليجرام + ويب |
| ⏻ إيقاف التشغيل | `shutdown /s /t 0` | نعم — تيليجرام + ويب |
| 📝 فتح المفكّرة | `notepad` | لا (إجراء آمن) |

## المزايا

- 🤖 **بوت تيليجرام** — يُظهر الأمر `/start` ثلاثة أزرار، مع خطوة تأكيد لإعادة التشغيل وإيقاف التشغيل
- 🌐 **واجهة ويب** — داكنة، ثنائية اللغة، بنفس الإجراءات الثلاثة مع نافذة تأكيد
- 🛡️ **قائمة بيضاء فقط** — لا أوامر مخصّصة، ولا تصفّح للملفّات، ولا لقطات شاشة
- 🔒 **مستخدم واحد** — لا يردّ البوت إلا على معرّف المحادثة (Chat ID) الخاصّ بك
- 🌍 **أربع لغات للتوثيق** — العربية الفصحى، والدّارجة المغربية، والإنجليزية، والفرنسية
- 🪶 **دون مكتبات خارجية** — Node.js خالص بمكتبته المعيارية فقط

## المتطلّبات

- نظام ويندوز 10/11
- Node.js 18 فأحدث (تحقّق بالأمر `node --version`)
- رمز بوت من [@BotFather](https://t.me/BotFather) + معرّف المحادثة من [@userinfobot](https://t.me/userinfobot)

## التثبيت

```bash
git clone https://github.com/xbitoi/terminal-telegram-control.git
cd terminal-telegram-control
npm install
node server.js
```

افتح **http://localhost:3770** في المتصفّح، أو نقرة مزدوجة على `run.bat`.

## الإعداد

**من الواجهة (مُستحسَن):** افتح الصفحة ← *إعدادات تيليجرام* ← الصق الرمز
ومعرّف المحادثة ← *حفظ*. يعمل البوت فوراً دون إعادة تشغيل.

**من الملفّ:** انسخ القالب واملأه:

```bash
cp config.example.json config.json
```

> ملفّ `config.json` مُتجاهَل في git. لا تنشر رمزك الحقيقي أبداً.

## الاستخدام

**تيليجرام:** أرسل `/start` ← اضغط 🔄 / ⏻ / 📝. يتطلّب إيقاف التشغيل وإعادة
التشغيل تأكيداً أولاً. تعمل الأوامر المباشرة `/restart` و`/shutdown` و`/notepad` أيضاً.

**الويب:** افتح `http://localhost:3770` ← *تشغيل* على أيّ بطاقة. تعرض الإجراءات
الخطيرة نافذة تأكيد.

## بنية المشروع

```
terminal-telegram-control/
├── server.js            # الخادم + البوت، وقائمة الإجراءات الثلاثة
├── public/index.html    # واجهة ويب داكنة ثنائية اللغة
├── config.json          # أسرارك (مُتجاهَل في git، تنشئه أنت)
├── config.example.json  # قالب
├── run.bat              # تشغيل بنقرة واحدة لويندوز
└── package.json         # دون اعتماديات
```

## الأمان

- يستحيل على الخادم تشغيل أيّ شيء خارج خريطة `ACTIONS` في `server.js` — راجعها في 30 ثانية.
- تُتجاهَل رسائل تيليجرام الواردة من أيّ معرّف محادثة آخر.
- يتطلّب إيقاف التشغيل وإعادة التشغيل ضغطة تأكيد ثانية دائماً.
- إذا تسرّب الرمز، أبطله عبر [@BotFather](https://t.me/BotFather) ← `/revoke`.
