# التحكم بالحاسوب عبر تيليجرام (بالدّارجة)

> **تحكم في حاسوبك الويندوز من تيليجرام أو المتصفح — 3 إجراءات ثابتة فقط.**
> إعادة التشغيل، الإطفاء، أو فتح المفكرة. بدون أوامر حرة، بدون مفاجآت.

## علاش هاد المشروع؟

معظم أدوات التحكم عن بعد كتنفذ أي أمر كتصيفطو — عملي، ولكن إلا تسرب توكن
البوت كيعني تنفيذ كامل عن بعد على حاسوبك. هاد المشروع دار العكس: السيرفر
كيقدر يشغل **3 أوامر مصرح بها فقط**، وأي حاجة أخرى مرفوضة. آمن، وساهل للمراجعة.

| الإجراء | الأمر المنفذ | تأكيد |
|---|---|---|
| 🔄 إعادة التشغيل | `shutdown /r /t 3` | نعم — تيليجرام + ويب |
| ⏻ الإطفاء | `shutdown /s /t 0` | نعم — تيليجرام + ويب |
| 📝 فتح المفكرة | `notepad` | لا (آمن) |

## المميزات

- 🤖 **بوت تيليجرام** — `/start` كتعرض 3 أزرار، مع خطوة تأكيد للإطفاء/التشغيل
- 🌐 **واجهة ويب** — داكنة، بالعربية والإنجليزية، نفس الإجراءات + نافذة تأكيد
- 🛡️ **لائحة بيضاء فقط** — لا أوامر مخصصة، لا تصفح ملفات، لا سكرين شوت
- 🔒 **مستخدم واحد** — البوت كيجاوب غير الـ Chat ID ديالك
- 🌍 **التوثيق بـ 4 لغات** — الفصحى، الدارجة المغربية، الإنجليزية، الفرنسية
- 🪶 **بدون مكتبات** — Node.js خام فقط

## المتطلبات

- ويندوز 10/11
- Node.js 18+ (تحقق بـ `node --version`)
- توكن بوت من [@BotFather](https://t.me/BotFather) + الـ Chat ID من [@userinfobot](https://t.me/userinfobot)

## التثبيت

```bash
git clone https://github.com/xbitoi/terminal-telegram-control.git
cd terminal-telegram-control
npm install
node server.js
```

حل **http://localhost:3770** في المتصفح. أو نقر مزدوج على `run.bat`.

## الإعداد

**من الواجهة (مستحسن):** حل الصفحة → *إعدادات تيليجرام* → لصق التوكن +
Chat ID → *حفظ*. البوت كيخدم مباشرة بلا ريستارت.

**من الملف:** نسخ القالب وعمرو:

```bash
cp config.example.json config.json
```

> `config.json` متجاهل في git. عمرك ما تنشر التوكن الحقيقي.

## الاستعمال

**تيليجرام:** صيفط `/start` → ضغط على 🔄 / ⏻ / 📝. الإطفاء والتشغيل كيطلبو
تأكيد أولاً. الأوامر المباشرة `/restart` و`/shutdown` و`/notepad` خدامة حتى هي.

**الويب:** حل `http://localhost:3770` → *تشغيل* على أي بطاقة. الإجراءات
الخطيرة كتعرض نافذة تأكيد.

## بنية المشروع

```

├── config.json          # أسرارك (git-ignored، كتصايبو انت)
├── config.example.json  # قالب
├── run.bat              # تشغيل بنقرة لويندوز

```

## الأمان

- السيرفر **مستحيل** يشغل شي حاجة خارج `ACTIONS` في `server.js` — راجعها في 30 ثانية.
- رسائل تيليجرام من Chat ID آخر كتجاهل.
- الإطفاء/التشغيل كيطلبو ضغطة تأكيد ثانية دائماً.
- إلا تسرب التوكن، لغيه عبر [@BotFather](https://t.me/BotFather) ← `/revoke`.
