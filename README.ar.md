# التحكّم بالحاسوب عبر تيليجرام

> **تحكَّم في حاسوبك العامل بنظام ويندوز من تيليجرام أو المتصفّح.**

## المزايا

| المجال | ما تحصل عليه |
|---|---|
| 🤖 **بوت تيليجرام** | قائمة بأزرار تطبيقاتك؛ إضافة التطبيقات وتعديلها وحذفها عن بُعد؛ وتشغيل بلمسة واحدة |
| ⌨️ **أزرار سريعة** | لوحة دائمة: لقطة الشاشة، الملفّات، السجلّ، الإيقاف، بدء التشغيل، فتح الواجهة، اللغة |
| 📸 **لقطة الشاشة** | التقاط شاشة الحاسوب واستلامها على تيليجرام، أو مشاهدتها في واجهة الويب (دون أدوات إضافية) |
| 📁 **إدارة الملفّات** | تصفّح الأقراص والمجلّدات، وتنزيل الملفّات من الحاسوب إلى الهاتف (45MB كحدّ أقصى)، ورفع الملفّات من الهاتف إلى الحاسوب؛ والرفع والتنزيل من واجهة الويب أيضاً، مع منتقي مجلّدات أصليّ لويندوز |
| ⏰ **الجدولة** | جدوِلة تشغيل أيّ تطبيق لاحقاً؛ تبقى الجدولة محفوظة بعد إعادة التشغيل؛ ويمكن إلغاؤها من تيليجرام أو الويب |
| 🕘 **السجلّ والشغّالة** | تتبّع حيّ للعمليات مع أزرار إيقاف لكلّ تطبيق، وحالة تطبيقات الإقلاع، وسجلّ آخر التشغيلات |
| 🔥 **مدير بدء التشغيل** | تشغيل تلقائي لكلّ تطبيق عند إقلاع ويندوز + مفتاح بدء الخادم مع ويندوز |
| ⚡ **إجراءات سريعة** | قفل الحاسوب، إفراغ سلّة المحذوفات، تصغير كلّ النوافذ، فتح مدير المهام |
| 🌐 **واجهة الويب** | لوحة داكنة ثنائية اللغة: إدارة التطبيقات، التشغيل والإيقاف، الجدولة، الملفّات، لقطات الشاشة، الإعدادات، النسخ الاحتياطي، وإرسال الرسائل والملفّات إلى تيليجرام |
| 💾 **النسخ الاحتياطي** | تصدير الإعدادات كاملة واستيرادها بصيغة JSON من واجهة الويب |
| 🛡️ **الأمان** | إعادة التشغيل والإطفاء يتطلّبان تأكيداً؛ والبوت مقيّد بمعرّف محادثتك؛ وحماية من الضغط المكرّر |
| 🌍 **لغتان** | العربية الكاملة (RTL) والإنجليزية في البوت والواجهة والتوثيق |
| 🐚 **الأصداف** | `cmd` وباورشل وGit Bash؛ ويمكن لكلّ تطبيق تسلسل عدّة أوامر |

## المتطلّبات

- نظام ويندوز 10/11
- Node.js 18 فأحدث (تحقّق بالأمر `node --version`)
- رمز بوت من [@BotFather](https://t.me/BotFather) ومعرّف المحادثة من [@userinfobot](https://t.me/userinfobot)

## التثبيت

```bash
git clone https://github.com/xbitoi/terminal-telegram-control.git
cd terminal-telegram-control
npm install
node server.js
```

افتح **http://localhost:3770** في المتصفّح، أو نقرة مزدوجة على `run.bat`.
لبدء التشغيل تلقائياً مع ويندوز نفّذ `install-startup.ps1` (دون صلاحيات مدير) أو فعّله من الواجهة / قائمة 🔥 في تيليجرام.

## الإعداد

**من الواجهة (مُستحسَن):** افتح الصفحة ← *إعدادات تيليجرام* ← الصق الرمز
ومعرّف المحادثة (ومجلّد التنزيل واللغة) ← *حفظ*. يعمل البوت فوراً.

**من الملفّ:** انسخ القالب واملأه:

```bash
cp config.example.json config.json
```

> ملفّ `config.json` مُتجاهَل في git. لا تنشر رمزك الحقيقي أبداً.

## الاستخدام

### تيليجرام

أرسل `/start` ← قائمة بأزرار تطبيقاتك. اضغط للتشغيل (إعادة التشغيل والإطفاء
يطلبان تأكيداً أولاً)، أو أدرها بأزرار ➕ إضافة / ✏️ تعديل / 🗑 حذف / ⏹️ إيقاف.

| الأمر | الوصف |
|---|---|
| `/start` و`/menu` | القائمة الرئيسية (التطبيقات) |
| `/screenshot` | التقاط شاشة الحاسوب |
| `/files` | تصفّح ملفّات الحاسوب |
| `/history` | التطبيقات الشغّالة وتطبيقات الإقلاع وآخر التشغيلات |
| `/stop` | إيقاف تطبيق شغّال |
| `/startup` | إعدادات التشغيل مع إقلاع ويندوز |
| `/schedules` | التشغيلات المجدولة (اضغط للإلغاء) |
| `/add` و`/edit` و`/delete` | إدارة التطبيقات |
| `/lang` | تبديل اللغة (عربي/إنجليزي) |
| `/browser` | فتح واجهة الويب على الحاسوب |

تمنحك لوحة الأزرار السريعة (⌨️ تحت خانة الكتابة) وصولاً فورياً إلى لقطة
الشاشة والملفّات والسجلّ والإيقاف وبدء التشغيل واللغة. وأيّ صورة أو فيديو أو
ملفّ ترسله إلى البوت يُحفَظ مباشرة في مجلّد التنزيل على الحاسوب.

### واجهة الويب

افتح `http://localhost:3770`: شغّل التطبيقات بـ ▶ وأوقفها بـ ⏹، وفعّل
التشغيل التلقائي لكلّ تطبيق عند الإقلاع، وجدوِل التشغيل، وتصفّح الملفّات
وارفعها وحمّلها، والتقط لقطات الشاشة، وغيّر إعدادات تيليجرام، ونفّذ
الإجراءات السريعة، وانسخ الإعدادات احتياطياً واستعدها.

### إضافة التطبيقات

لكلّ تطبيق اسم وأمر واحد أو أكثر. أمثلة:

| التطبيق | الأوامر |
|---|---|
| المفكّرة | `notepad` |
| إعادة تشغيل الحاسوب | `shutdown /r /t 3` |
| إطفاء الحاسوب | `shutdown /s /t 0` |

أضفها من تيليجرام (`/add` يرشدك: الاسم ثم الأمر) أو من واجهة الويب.

## بنية المشروع

```
terminal-telegram-control/
├── server.js               # خادم HTTP + بوت تيليجرام (كلّ المزايا)
├── public/index.html        # واجهة ويب داكنة ثنائية اللغة
├── config.json              # تطبيقاتك وأسرارك (مُتجاهَل في git، تنشئه أنت)
├── config.example.json      # قالب بداية (إعادة التشغيل/الإطفاء/المفكّرة)
├── run.bat                  # تشغيل بنقرة مزدوجة لويندوز
├── install-startup.ps1      # تسجيل بدء التشغيل مع ويندوز (دون مدير)
├── test-per-app-startup.sh  # فحوصات ميزة التشغيل التلقائي
└── package.json
```

## الأمان

- يتجاهل البوت الرسائل الواردة من أيّ معرّف محادثة غير معرّفك.
- تتطلّب إعادة التشغيل والإطفاء تأكيداً صريحاً دائماً.
- يظهر الرمز مقتطعاً في كلّ مكان؛ وقيمته الكاملة في `config.json` المحليّ فقط.
- حافظ على سرّية رمز البوت. وإذا تسرّب فأبطله عبر [@BotFather](https://t.me/BotFather) ← `/revoke`.
